✈️ GitHub Pages Offline Setup
Host Free on GitHub Pages
  1. Create a new repository on GitHub (e.g., workout-mosaic).
  2. Upload all files from this folder (index.html, manifest.webmanifest, sw.js, logo.png).
  3. Go to Settings → Pages in your GitHub repo.
  4. Select Branch: main / root and click Save.
  5. Open the URL on your phone or computer, tap "Add to Home Screen", and it will work 100% offline in Airplane Mode!
